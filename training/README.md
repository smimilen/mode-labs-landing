## Архитектура (кратко, полная версия — в шапке `3_train_lora.py`)

IDM-VTON — не один UNet, а связка: **TryonNet** (основной denoising UNet,
13-канальный вход: шум + маска + latent человека без одежды + DensePose) +
**GarmentNet** (второй UNet, отдаёт garment_features, которые TryonNet
подмешивает в self-attention) + **IP-Adapter** (CLIP image encoder +
Resampler, второй визуальный канал описания одежды) + два текстовых
энкодера SDXL. LoRA (`peft`) вешается на `to_k/to_q/to_v/to_out.0` в
attention-слоях TryonNet поверх уже обученного чекпоинта `yisol/IDM-VTON` —
это дообучение под нишу, а не обучение примерке с нуля.

## Известные ограничения

- **Датасет:** VITON-HD (CC BY-NC 4.0, только некоммерческое использование).
  Для коммерческой версии — дообучение на собственных данных платформы.
- **Подписи одежды:** если `vitonhd_train_tagged.json` не найден в архиве,
  `1_prepare_dataset.py` подставляет дефолтные ({}), реальный код train_xl.py
  в этом случае использует общую подпись вроде "shirts" — качество текстового
  кондиционирования будет ниже, чем с настоящими тегами.
- **VRAM (T4, 15-16GB):** две SDXL-модели + два текстовых энкодера + CLIP
  image encoder одновременно в памяти — на пределе даже с LoRA, fp16, grad
  checkpointing, 8-bit Adam. Дефолты (512×384, batch=1) — минимум, который
  вообще может влезть, не "рекомендуемое качество".
- Датасет и промежуточные чекпоинты живут только в Kaggle Notebook Output —
  ничего не сохранено персистентно вне Kaggle. Финальную LoRA (после
  успешного обучения) нужно будет скачать и залить в свой репозиторий на
  HuggingFace.
